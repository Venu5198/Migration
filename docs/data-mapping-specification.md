# Data mapping specification

Mappings identify source entity, sheet, field, target entity and field; mapping type (`direct`, `transformed`, `derived`, `excluded`, `unresolved`); required status; transformation configuration; status; and version.

Only mappings with a non-unresolved type can be approved. Country and employment-status dictionaries, employee/assignment key policy, required target fields, Host Job Title versus Host Job Level semantics, target vocabulary, and matching/upsert policy remain client decisions. They are not inferred from historical workbooks.
